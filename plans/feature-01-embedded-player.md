# Feature 01: Embedded Player with Timestamp Sync

## Context

Currently, the set-level HTML (`html_formatter.py`) renders deep-link timestamps as `<a>` tags that open the source YouTube/SoundCloud video in a new browser tab. This breaks the user's flow — they leave the setlist page to hear the track. This feature embeds the video player directly in the HTML page and makes every timestamp click seek within the embedded player instead.

## Goal

- Embed a YouTube or SoundCloud player at the top of the set-level HTML page
- Clicking any track's timestamp seeks the embedded player to that time (no new tab)
- As the player plays, highlight the "now playing" track card and timeline segment in real-time
- Add a small play button on each track card for one-click playback from that track's start time

## Files to Modify

- **`html_formatter.py`** — the only file that needs changes (all HTML/CSS/JS is generated here)

## Existing Code Understanding

### Source URL Detection
`output_formatter.py:make_source_url()` (line 30-76) already parses source URLs to detect platform:
- YouTube: `youtube.com` or `youtu.be` → extracts `video_id`
- SoundCloud: `soundcloud.com` → builds `base_url#t=`
- The `source_url` comes from `mix_info['url']` and is passed through to `_build_track_data()`

### Current Deep Links
In `_render_track_cards()` (line 66-137), each track card renders a `<a class="track-time-link" href="..." target="_blank">` that opens the source at timestamp in a new tab.

### Current Timeline Click
In the JS constant `JS` (line 520-685), clicking a timeline segment calls `setActive(idx)` which scrolls to the track card. It does NOT interact with any player.

### Track Data Available
Each track dict from `_build_track_data()` includes:
- `start_time` (float seconds)
- `end_time` (float seconds)
- `source_deep_link` (full URL with timestamp)
- `position` (1-indexed track number)

## Implementation Plan

### Step 1: Detect Platform from Source URL

Add a helper function at module level in `html_formatter.py`:

```python
def _detect_platform(source_url: str) -> tuple[str, str]:
    """Detect platform and extract embed identifier from source URL.

    Returns:
        (platform, embed_id) where platform is 'youtube', 'soundcloud', or 'unknown'
        For YouTube: embed_id is the video ID
        For SoundCloud: embed_id is the full track URL (needed for SC widget)
    """
```

Parse logic (reuse patterns from `output_formatter.py:make_source_url`):
- YouTube (`youtube.com`): extract `v=VIDEO_ID` from query params
- YouTube (`youtu.be`): extract video ID from path
- SoundCloud (`soundcloud.com`): use the full URL as embed_id (SC widget needs the track URL)
- Anything else: return `('unknown', '')`

### Step 2: Render the Embedded Player HTML

Add a new function `_render_player(platform: str, embed_id: str) -> str` that returns the player HTML.

**YouTube embed:**
```html
<div class="player-wrap" id="playerWrap">
  <div id="ytPlayer"></div>
</div>
```
The actual `<iframe>` will be created by the YouTube IFrame Player API JS (loaded async). This gives us programmatic control via `player.seekTo()`, `player.getCurrentTime()`, etc.

**SoundCloud embed:**
```html
<div class="player-wrap sc" id="playerWrap">
  <iframe id="scWidget" scrolling="no" frameborder="no" allow="autoplay"
    src="https://w.soundcloud.com/player/?url=ENCODED_URL&auto_play=false&show_artwork=true&color=%2300e676&hide_related=true">
  </iframe>
</div>
```
The SoundCloud Widget API JS gives us `widget.seekTo(ms)`, `widget.getPosition()`, etc.

**Unknown platform:** Return empty string; keep existing deep-link behavior as fallback.

**CSS to add to the `CSS` constant:**
```css
.player-wrap {

  overflow: hidden;
  border: 1px solid #222;
  background: #111;
}
.player-wrap iframe, .player-wrap #ytPlayer {
```

Place this section between the header and the stats bar in the HTML template (around line 1237 in `save_setlist_html()`).

### Step 3: Load Platform JS APIs

Add platform-specific `<script>` blocks. These are generated by a new function `_render_player_js(platform: str, embed_id: str, tracks: list) -> str`.

**YouTube IFrame API:**
```javascript
var tag = document.createElement('script');
tag.src = "https://www.youtube.com/iframe_api";
var firstScriptTag = document.getElementsByTagName('script')[0];
firstScriptTag.parentNode.insertBefore(tag, firstScriptTag);

var player;
function onYouTubeIframeAPIReady() {
  player = new YT.Player('ytPlayer', {
    videoId: 'VIDEO_ID_HERE',
    playerVars: { autoplay: 0, modestbranding: 1, rel: 0 },
    events: {
      onReady: function() { console.log('YT player ready'); },
      onStateChange: function(e) {
        if (e.data === YT.PlayerState.PLAYING) startNowPlaying();
        else stopNowPlaying();
      }
    }
  });
}

function seekPlayer(seconds) {
  if (player && player.seekTo) {
    player.seekTo(seconds, true);
    player.playVideo();
  }
}
```

**SoundCloud Widget API:**
```html
<script src="https://w.soundcloud.com/player/api.js"></script>
<script>
var widget = SC.Widget(document.getElementById('scWidget'));
widget.bind(SC.Widget.Events.READY, function() {
  console.log('SC widget ready');
});
widget.bind(SC.Widget.Events.PLAY, function() { startNowPlaying(); });
widget.bind(SC.Widget.Events.PAUSE, function() { stopNowPlaying(); });

function seekPlayer(seconds) {
  widget.seekTo(seconds * 1000); // SC uses milliseconds
}
</script>
```

### Step 7: "Now Playing" Indicator (Polling)

Add to the JS:

```javascript
let nowPlayingInterval = null;

function startNowPlaying() {
  if (nowPlayingInterval) return;
  nowPlayingInterval = setInterval(updateNowPlaying, 1000);
}

function stopNowPlaying() {
  clearInterval(nowPlayingInterval);
  nowPlayingInterval = null;
}

function updateNowPlaying() {
  // YouTube path
  if (typeof player !== 'undefined' && player.getCurrentTime) {
    highlightTrackAt(player.getCurrentTime());
    return;
  }
  // SoundCloud path
  if (typeof widget !== 'undefined' && widget.getPosition) {
    widget.getPosition(function(pos) { highlightTrackAt(pos / 1000); });
  }
}

function highlightTrackAt(seconds) {
  const match = trackTimes.find(t => seconds >= t.start && seconds < t.end);
  if (match && match.idx !== String(activeIdx)) {
    clearActive();
    setActive(String(match.idx));
  }
}
```

### Step 8: Timeline Click Also Seeks Player

Modify the existing timeline segment click handler in the `JS` constant. After `setActive(idx)`, add:

```javascript
const trackTime = trackTimes.find(t => t.idx === idx);
if (trackTime) seekPlayer(trackTime.start);
```

## Wiring It All Together in save_setlist_html()

In the `save_setlist_html()` method (line 1139):

1. Call `platform, embed_id = _detect_platform(source_url)` early
2. Call `player_html = _render_player(platform, embed_id)` — insert between header and stats
3. Pass `platform` to `_render_track_cards(tracks, platform)`
4. Call `player_js = _render_player_js(platform, embed_id, tracks)` — insert before `</body>`
5. Generate `trackTimes` JS array from `tracks` list — include in the player JS block
6. The existing `JS` constant stays mostly unchanged; the timeline click handler gets a small addition
